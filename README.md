# Курс: от LLM к агентам в закрытом контуре

Практический курс о том, что такое большие языковые модели (LLM) и как перейти от «умного чата» к **агентам** — помощникам, которые выполняют многошаговые задачи под вашим контролем.

Все примеры и практика построены на **закрытом контуре** компании:
- локальные модели с открытыми весами (семейства **Qwen**, **DeepSeek** и другие) работают на наших серверах через **vLLM**;
- чат в браузере — **Open WebUI** (общие пресеты и базы знаний для команды);
- приложение на компьютере — **Chatbox** (чат и агентный режим Work Mode, история хранится локально);
- агентная среда — расширение **Kilo Code** для VS Code;
- данные не уходят во внешние облачные сервисы, у моделей нет выхода в интернет.

## Для кого

- Для менеджеров, аналитиков, тестировщиков: программировать не нужно.
- Для начинающих разработчиков, которые хотят собрать первого агента осознанно.

## Что вы будете уметь после курса

- Объяснять, как работает LLM, почему она уверенно ошибается и как это проверять.
- Подключить Kilo Code к серверу моделей контура и сразу выставить безопасные права.
- Выбирать модель стенда под задачу.
- Писать промпты, делать пресеты в Open WebUI и файлы правил проекта (AGENTS.md).
- Ставить агенту задачу брифом с критериями приёмки и принимать результат по фактам.
- Выбирать между чатом, workflow, одним агентом и командой агентов.
- Определять, что агенту можно делать самому, что только с подтверждением, а что запрещено.
- Проверять агента на эталонном наборе (evals) и отлаживать его по логу действий.

## Чат и агент

- **Чат** (Open WebUI) отвечает на сообщение текстом. Всё остальное делаете вы.
- **Агент** (Kilo Code, Chatbox Work Mode) получает цель и в цикле сам выбирает шаги: читает файлы, ищет, вызывает инструменты, смотрит на результат и повторяет, пока задача не решена. Границы задаёте вы, результат принимаете тоже вы.

Разница примерно как между «посоветуй рецепт» и «приготовь ужин, но продукты покупаем только с моего согласия».

## Как устроен курс

17 уроков, примерно 5–6 часов, по 20–45 минут на урок. Каждый урок построен одинаково: цели, объяснение, частая ошибка новичка, «главное за 30 секунд», словарик, практическое задание и «Проверь себя» с ответами в конце.

Через весь курс проходит **сквозной проект «Помощник по разбору заявок»** — в двух вариантах: пресет в Open WebUI и агент в Kilo Code, который читает заявки из файлов или учебного проекта Jira. В каждом уроке вы делаете один шаг проекта, а к уроку 11 собираете помощника целиком. Если Kilo Code у вас ещё не настроен, для каждого задания есть вариант в Open WebUI или «на бумаге». Готовые обезличенные заявки для практики лежат в уроке 00.

Начните с [урока 00](00-kak-prohodit-kurs.md), затем [00a](00a-stend.md) — подключение к стенду.
